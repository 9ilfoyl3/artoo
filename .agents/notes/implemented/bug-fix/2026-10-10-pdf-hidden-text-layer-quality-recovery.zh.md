# Agent Note: PDF hidden text-layer quality recovery

Status: implemented

## Problem

扫描 PDF 可能同时包含整页图片和隐藏文本层。既有的
[PDF scan text-layer deduplication](./2026-09-23-pdf-scan-text-layer-deduplication.zh.md)
决策正确地避免在文本层可用时重复 OCR 整页图片。但 `TextCleaner` 假设每页都是
A4 高度（`842pt`）。宽页或其他非标准页面因此可能把大部分正文当成页脚并删除。

`20_机动车违法查询.pdf` 事件同时暴露了这两个问题。该页为 `3798 x 2483pt`，
但清洗器使用 `842pt` 高度，把 `799.9pt` 以下所有短文本块删除，并将 `474`
个字符缩减成错误残文：
`机动车违法查询\n号牌种类0 2 小型汽车只脑三部A 2 8 8 W B6 0 3 1`。
隐藏文本层还把 ASCII 标识符拆成单字符 token。按页 Paddle OCR 比原生文本层更准确，
但 pipeline 认为文本层可用，因此从未调用 OCR。

`动火作业票（测试1）.pdf` 事件暴露了第二个路由缺口。第 1、2 页分别只有 6、5 个
原生字符，印刷表单字段属于视觉内容，手写签名是 16 张小嵌入图。文档原生字符总数
超过 10，且没有整页扫描底图，因此 pipeline 跳过整页 OCR，只逐张 OCR 签名小图，
最终产生大量以 `[图片内容]` 包裹的碎片。

## Decision

PDF loader 现在在 `LoadResult.page_heights` 中记录每页真实高度，`TextCleaner`
使用这些高度过滤页眉和页脚。如果页面高度不可用，cleaner 跳过 bbox 过滤，而不是
套用 A4 假设。当清洗后保留的非空白字符少于 30% 时，它还返回原始内容。

PDF loader 还会逐页记录 `page_has_usable_text`。pipeline 只选择“文本层不可信
且存在图片内容”的页面，并按页码请求 OCR。只接受图片的 Provider 只渲染所选页面；
直接接受 PDF 的 Provider 仍可收到整份文件，但只有请求页的结果会参与合并。
OCR 原始页码通过 `PreparedInput` 和 `OCRManager` 保留，不再从 1 重新编号。

选择性 OCR 只替换 OCR 返回非空文本的页面。可信文本页和 OCR 失败页保留原始文本。
已成功整页 OCR 的页面会移除其嵌入图片，避免再次输出 `[图片内容]`；可信文本页上
的普通图片仍沿用既有 OCR 追加逻辑。`TextCleaner` 在页面 block 为空时保留 OCR
页文本，而不是把该页重建为空。

其他混合扫描页仍保留原有低质量隐藏文本层规则：整页背景图片与单字符 ASCII
字母数字 token 的碎化特征同时存在时优先 OCR。如果所有 OCR 都没有返回文本，
则回退原始 PDF 文本层。

## Alternatives considered

**对所有混合文本层都执行 OCR。** 否决，因为既有去重决策有意避免对可用文本层重复
OCR，无条件 OCR 会为正常扫描 PDF 增加成本和延迟。

**任意页面文本稀疏时都执行整篇 OCR。** 否决，因为长文本 PDF 中只有一个问题页时，
这会重新 OCR 所有健康页，并用精度更低的 OCR 文本替换原生文本。

**始终保留原生文本层，只修复页面高度问题。** 对比输出后否决：原生文本层保留了
字段，但数字被拆开，包含 `黄波区`、`非警运` 等错误字符，标签顺序混乱，并带有法院
水印文本。按页 Paddle OCR 得到的字段更干净、更准确。

**OCR 为空时将原生文本层作为第一回退。** 接受。优先使用 OCR 以获得质量，但原生
文本层比用空的 OCR 结果替换非空文档更安全。

**保留固定 A4 高度假设。** 否决，因为源 PDF 的页面尺寸直接否定了这个假设，而且
同一缺陷会影响其他非标准扫描件。

## Consequences

包含图片的稀疏文本页，包括只有签名图片的表单页，现在会进入选择性整页 OCR，
且不会重新 OCR 健康文本页。没有图片的纯短文本页、真正的空白页和文本层可信页仍走
既有路径。对于缺失或异常尺寸，cleaner 会更保守，可能保留部分页眉或页脚噪声，
但不会冒数据丢失风险。新增页面元数据默认空列表，因此既有 `LoadResult` 构造方式
保持兼容。

## Testing

回归测试覆盖非 A4 真实页面高度、缺失高度时的安全路径、30% 内容损失保护、正常 A4
页眉页脚移除、碎化文本检测，以及整页背景图前提。新增测试覆盖页面文本层标志、
选择性页码、合并时保留原生页、只渲染请求页、恢复 OCR 原始页码，以及 cleaner
对无 block 的 OCR 页保留文本。`20_机动车违法查询.pdf` 加载后页面高度为 `2483.0`，
会被识别为低质量混合文本层，清洗后保留 `441` 个字符，而不是此前 42 个字符的错误
残文。`动火作业票（测试1）.pdf` 会选择第 1、2 页执行 OCR，并跳过空白第 3 页。
