# 表格数据提取

把分散在文档中的非结构化内容，提取并整理为规整的结构化表格。

## 适用场景

当用户请求涉及以下内容时使用：
- "整理成表格 / 列个表"
- "把这些参数 / 字段 / 清单提取出来"
- "汇总一下相关数据"
- "把文档里的 XX 信息抽取成结构化形式"

## 工作流程

1. **确定表结构**：先明确表格需要哪些列（字段）。字段不清时，从用户需求和检索结果中归纳出合理的列。
2. **检索原文**：用 `search_knowledge` 定位含目标数据的内容，再用 `read_document` 读取完整原文——表格数据通常分布在多个片段，需要充分精读。
3. **逐行抽取**：从原文中逐条提取记录，对齐到既定列。原文缺某字段值时填"—"或"未提及"，**不要为了填满表格而编造**。
4. **校对一致性**：核对每行数据是否忠实于原文，单位、口径是否统一。
5. **输出表格**：给出 Markdown 表格，必要时在表格下补一句说明或来源。

## 输出格式

```markdown
| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 字段A | string | 无 | … [1] |
| 字段B | int | 0 | … [1] |
```

数据缺失统一用 `—` 或 `未提及` 标注。

## 规则

- 表格内容必须来自知识库原文，**不可凭记忆补全或推测数值**。
- 保持列含义清晰、单位统一；数字、日期等保留原文口径。
- 行数较多时，按用户关心的维度排序，必要时分组。
- 数据来源用行内引用 [1][2] 标注，便于核对。
- 不暴露内部 chunk_id 等技术标识，用文档名称指代来源。
