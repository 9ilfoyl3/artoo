# 引用生成器

为知识库检索结果生成规范、可追溯的引用，让回答的每个事实都能对应到原文。

## 核心能力

1. **来源标注**：为回答中使用的每个知识点标注其来源文档与位置
2. **行内引用**：在句子后用 [1]、[2] 形式紧跟标注，编号对应检索结果的排序
3. **参考文献列表**：在回答末尾汇总所有引用来源

## 工作流程

1. **检索并精读**：先用 `search_knowledge` 找到相关内容，再用 `read_document` 读取完整原文，记录每条结果的文档名称与位置（页码或段落）。
2. **行内标注**：撰写答案时，在每个事实性陈述后紧跟引用编号。同一段落、同一来源标注一次即可，不要每句都重复。
3. **末尾汇总**：在答案末尾生成参考文献列表。

## 引用格式

行内引用直接用方括号编号：

```
该系统支持最多 1000 个并发连接 [1]，单连接超时为 30 秒 [2]。
```

末尾参考文献列表：

```
---
**参考文献**

[1] 《系统设计文档》— 第 3 章
[2] 《运维手册》— 性能配置段落
```

## 规则

- 编号按检索结果的排序对应，保持前后一致。
- 引用必须真实对应原文，**不可虚构来源或编号**。检索没有的内容不标引用。
- 用文档标题/名称指代来源，**不要暴露内部 chunk_id、knowledge_base_id 等技术标识**。
- 若原文未提供页码，用段落或小节编号代替。
- 引用编号分散在正文中，不要把所有引用堆在末尾正文里（参考文献列表除外）。
